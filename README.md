# Expense-_Tracker

A modern Expense Tracker web application built with React. It allows users to manage income, expenses, savings, and investments while viewing their overall balance and transaction history. The application also provides a visual breakdown of finances and supports dark mode and CSV export.
<br><br>
## Features
1. Add income, expenses, savings, and investments
2. Calculate total balance automatically
3. View financial breakdown using a donut chart
4. Display transaction history
5. Filter transactions by category
6. Delete transactions
7. Dark mode support
8. Export transaction data as CSV
9. Store transactions and preferences in the browser
10. Responsive design for different screen sizes
11.Automatically generate unique transaction IDs
