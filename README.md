# Expense-_Tracker

A modern Expense Tracker web application built with React. It allows users to manage income, expenses, savings, and investments while viewing their overall balance and transaction history. The application also provides a visual breakdown of finances and supports dark mode and CSV export.
<br><br>
Features
Add income, expenses, savings, and investments
Calculate total balance automatically
View financial breakdown using a donut chart
Display transaction history
Filter transactions by category
Delete transactions
Dark mode support
Export transaction data as CSV
Store transactions and preferences in the browser
Responsive design for different screen sizes
Automatically generate unique transaction IDs
